# Events API

### REST API for Event Management and Attendance

Events API is a backend application built with Node.js, Express and MongoDB for managing users, events and attendee registrations.

The API includes JWT-based authentication, role support, relational data with Mongoose references and event revenue calculations.

---

## Core Features

- User registration and login
- JWT authentication
- User roles (`user` / `admin`)
- Event creation and retrieval
- User registration for events
- Retrieval of events for the authenticated user
- Event revenue calculation
- Total revenue calculation
- MongoDB relationships using ObjectId references
- Swagger documentation
- REST Client endpoint collection for local testing

## Data Model

### User

```text
User
├── name
├── lastName
├── email
├── password
├── role
└── createDate
```

Users can authenticate and register for events.

### Event

```text
Event
├── title
├── description
├── date
├── location
├── price
├── attendees[]
└── createDate
```

The `attendees` field stores references to registered users through MongoDB ObjectIds.

This allows the API to model the relationship between users and events without duplicating user data.

---

## Authentication

Authentication is handled through JSON Web Tokens.

After login, the token must be included in protected requests using the authorization header:

```http
Authorization: Bearer <TOKEN>
```

Protected endpoints validate the token before allowing access to the requested resource.

---

## API Capabilities

### Users

- Register a new user
- Authenticate with email and password
- Access protected resources

### Events

- Create events
- Retrieve events
- Register authenticated users as attendees
- Retrieve events associated with the authenticated user

### Revenue

The API can calculate:

- Revenue generated by a specific event
- Total revenue generated across events

Revenue is derived from event prices and attendee registrations.

## Environment Variables

```env

DATABASE_URL=your_mongodb_connection_string

```

Never commit real credentials or secrets to the repository.
